\# MYProject



\## Description

A Python project developed as part of the APDS Tutorial 01.



\## Environment

\- Python 3.10

\- Conda environment: myenv



\## Installation

Activate the environment:



&#x20;   conda activate myenv



Install the dependencies:



&#x20;   python -m pip install -r requirements.txt



\## Project Structure

\- data/: datasets

\- notebooks/: Jupyter notebooks

\- src/: Python source code

\- outputs/: generated results
